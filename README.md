## What it does

`main.py` writes one deadpan one-star review to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> One star. Gravity: held everything down perfectly for billions of years, then dropped my phone once, face-down. Unforgivable.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
